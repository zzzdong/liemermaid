# Mermaid 饼图（Pie Chart）语法参考

> 来源：Mermaid 官方文档 — <https://mermaid.js.org/syntax/pie.html>
> 覆盖至 v11.16.0+（Donut 图、图例位置等）。本文档为 liemermaid 的 `pie` 解析提供语法对照。

## 1. 语法结构总览

```
pie [showData]                ← 关键字 + 可选参数
    [title 标题文本]           ← 可选标题
    "标签1" : 数值1            ← 数据条目
    "标签2" : 数值2
```

## 2. 各语法元素详解

### `pie` 关键字（必需）

- 以 `pie` 关键字开头，标识这是一个饼图图表。

### `showData`（可选）

- 作用：在图例文本**之后**显示实际数据数值。
- 位置：紧跟 `pie` 关键字之后，如 `pie showData`。

### `title`（可选）

- 作用：为饼图添加标题。
- 语法：`title` 后跟字符串类型的标题值，如 `title 某季度销售占比`。

### 数据条目（必需）

每条数据由**标签**和**数值**组成：

- **标签（label）**：必须用英文双引号 `" "` 包裹，作为扇区名称标识。
- **冒号分隔符**：标签与数值之间用英文冒号 `:` 分隔，如 `"搜索引擎" :`。
- **数值（value）**：必须是**正数值**（大于零），最多支持**两位小数**，如 `45.5`。

### 扇区排序规则

饼图扇区**按标签出现的顺序**顺时针排列。

## 3. 完整语法规范

```
pie [showData] [title 标题值]
    "数据键1" : 数值1
    "数据键2" : 数值2
```

## 4. 限制与注意事项

| 约束项 | 说明 |
| ------ | ---- |
| 数值必须为正数 | 不允许负数，负数会导致错误 |
| 数值必须大于零 | 零值也不允许 |
| 小数位数 | 最多支持两位小数 |
| 标签引号 | 必须使用英文双引号包裹 |

## 5. 扩展功能（v11.16.0+）

### 环形图（Donut Chart）

- 通过配置 `donutHole` 参数实现，合法值范围 `0` 到 `0.9`。

### 图例位置（Legend Position）

- 配置 `legendPosition`，合法值：`top`、`bottom`、`left`、`right`、`center`，默认 `right`。

### 扇区高亮（Highlight Slice）

- 配置 `highlightSlice`，可指定匹配的标签进行高亮；设为 `'hover'` 时悬停扇区高亮。

## 6. 完整示例

```
pie showData
    title 某季度各渠道访问来源占比
    "搜索引擎" : 45.5
    "直接访问" : 30.0
    "社交媒体" : 15.25
    "外部链接" : 9.25
```

## 7. 常见错误规避

1. 不要使用负数值或零值——会报错。
2. 标签必须加双引号——缺少引号导致解析失败。
3. 数值最多两位小数——超过可能无法正确解析。
